## Why?

Cloud-based VMs often configure `cloud-init` to write the `/etc/hosts` file. That will cause no problem except the line `127.0.1.1 hostname`. The entry breaks my intended setup, so I disable it using a simple `systemd` service, since I really do not want to modify the config of `cloud-init`.

## How

Create new file `/etc/systemd/system/fix-hosts.service` with the following content

```ini
# /etc/systemd/system/fix-hosts.service

[Unit]
After=cloud-init.service

[Service]
Type=oneshot
ExecStart=/bin/sed -i '/^127\.0\.1\.1/d' /etc/hosts

[Install]
WantedBy=multi-user.target
```

Then enable it

```bash
sudo systemctl enable fix-hosts.service
```

Now, reboot if you want to, and relax.
