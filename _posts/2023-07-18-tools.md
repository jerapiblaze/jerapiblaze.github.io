## PyTorch-Test [gist]

A Python script which prints all of key information about your PyTorch environment.

![pytorch-test in action](pytorch-test.png)

Run on <i class="fa-brands fa-linux"></i>Linux
```bash
curl -fsSL https://gist.githubusercontent.com/jerapiblaze/5dd33f45dcaba2a812d0761d1650696d/raw/64e042df4e8c889d5efd8a537db15ca31a0c59c6/torch_test.py | python | less
```

Run on <i class="fa-brands fa-windows"></i> Windows
```powershell
Invoke-WebRequest -Uri " https://gist.githubusercontent.com/jerapiblaze/5dd33f45dcaba2a812d0761d1650696d/raw/64e042df4e8c889d5efd8a537db15ca31a0c59c6/torch_test.py" -UseBasicParsing | Select-Object -ExpandProperty Content | python | Out-Host -Paging
```

## Tee's API

My cloudflare worker providing mock API and some other stuffs.

<i class="fa-brands fa-github"></i> [Source code](https://github.com/jerapiblaze/tapi) <i class="fa-solid fa-book"></i>[ Documentation](https://tapi.j12tee.qzz.io){:target="_blank"}

### YetAnotherOnlineIP-Check

YetAnotherOnlineIP-Check (YAOI-C) is a Cloudflare worker which returns various information about the IP address of the client. It is a part of my mock API suite.

```
GET: https://tapi.j12tee.qzz.io/api/v1/ipcheck
GET: https://tapi.j12tee.qzz.io/ipcheck.api
```

Try it now: [>> WebUI](https://tapi.j12tee.qzz.io/ipcheck){:target="_blank"} [>> JSON](https://tapi.j12tee.qzz.io/api/v1/ipcheck){:target="_blank"}

### TimeDateManualAcknowledgement

TimeDateManualAcknowledgement (TDMA) is a Cloudflare worker which returns the servers' current time. It is a part of my mock API suite.

```
GET: https://tapi.j12tee.qzz.io/api/v1/timedate
GET: https://tapi.j12tee.qzz.io/timedate.api
```

Try it now: [>> WebUI](https://tapi.j12tee.qzz.io/timedate){:target="_blank"} [>> JSON](https://tapi.j12tee.qzz.io/api/v1/timedate){:target="_blank"}

> Funfact: My [about page](/about){:target="_blank"} and my [SCSS profile page](https://scss.tcd.ie/~nguyenm2){:target="_blank"} use this TDMA API for time synchronizing.

## Hust-hotspot-autologin

I'm tired about our lab's internal network at HUST being disconnected and requiring manual login every ~~24~~ 8 hours. This script will check if login is needed and automatically send login request without the need of entering username/password. To make it run periodicly, use `cronjob` (for Linux friends) or `Task Scheduler` (for Windows friends).

## PlainText & DynamicWallpaper [Rainmeter skin]

- `dynamicBackground`: auto dark/light theme based on various settings.
- `powermeasure`: a floatie measure resource usage (Battery level, CPU, RAM, network)
